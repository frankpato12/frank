INSTALLATION
------------
1. Make a backup copy of your current website folder.
2. Extract this ZIP file.
3. Replace the existing HTML, CSS and JavaScript files with the files here.
4. Keep your existing images folder and its image files.
5. Upload/redeploy the updated website.
